# Superstore Sales Analysis 📊

## Project Overview
This project analyzes superstore sales data to identify 
business insights and recommendations using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights
- Electronics contributes 93.4% of total sales
- Dhaka region is the top performing region
- Sales dropped dramatically in Sep-Oct — needs investigation
- Food and Education segments are underperforming

## Recommendations
- Increase investment in Electronics
- Run special campaigns in Sep-Oct
- Improve marketing in Sylhet and Rajshahi
- Reconsider pricing for Food and Education

## Dataset
50 orders across 4 categories and 4 regions over 10 months.
